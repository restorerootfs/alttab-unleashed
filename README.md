# AltTab Unleashed
This fork of AltTab pulls in the latest build of AltTab, enables premium features, and codesigns it with an ad-hoc signature.  
**I am sick and tired of developers locking previously free features behind a paywall. You can add new features and not shove premium in the user's face, you know.**.
